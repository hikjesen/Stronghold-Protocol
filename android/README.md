# Android APK wrapper

This branch contains an experimental Android wrapper for Stronghold Protocol.

## User experience

The APK embeds:

- the Stronghold Protocol Node.js server and browser client;
- production npm dependencies and downloaded game assets;
- an Android build of Node.js 24;
- a fullscreen landscape WebView.

On first launch the game payload is unpacked into the app's private storage.
The app then starts Node in a background thread, waits for
`http://127.0.0.1:3000/healthz`, and opens the game automatically.

No Termux, Node.js installation, shell, or manual server setup is required.

## Current build target

The first test build targets **arm64-v8a** Android devices and uses the normal
Android debug signing key generated by the build runner. It is intended for
sideload testing.

The game opens with `?board=2d` by default for better mobile compatibility.
